# @deepseek-ai/dsh-client-ui-auth-login

[English](README.md) | 中文

DeepSeek Harness 的纯展示 Web 登录入口。该插件向 `shell.overlay` 插槽贡献一个全屏界面，
提供相互独立的普通用户与管理员模式、必填项校验、密码显隐控制，以及可选的账号记忆功能。
本地表单校验通过后，浮层关闭并显示工作台。

本包有意不校验凭据、不建立用户身份、不签发令牌，也不授予权限。普通用户／管理员切换只会
改变文案和视觉样式。未来接入认证适配器时，应把本地提交边界替换为 Host 调用，并且只能根据
Host 验证后的结果派生权限，禁止依据界面上选择的模式授予权限。

Web bundle 通过 `cordis.patch.yml` 激活该插件。其他组装若要启用它，需要在 bundle 依赖和
client Cordis 配置中加入 `@deepseek-ai/dsh-client-ui-auth-login`。插件会等待
`shell.overlay` 就绪，因此不依赖插件的 apply 顺序。

## 模型体验

无，因为登录表单内容与所选模式都不会进入模型请求。

#### KV Cache 影响

无；本包既不组装也不发送提供方请求。

## 已知限制与暂缓事项

- **尚无认证**：任意非空账号与密码都能关闭浮层。
- **尚无授权**：管理员模式不会赋予管理员权限。
- **展示状态仅保存在本地**：只有账号和所选模式可能写入 `localStorage`；密码与认证状态
  绝不会持久化。
- **没有服务端会话**：刷新页面后会再次显示登录浮层。
